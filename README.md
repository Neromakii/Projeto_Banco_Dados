O projeto desenvolvido consiste em um sistema de E-commerce online, no qual os usuários podem realizar cadastro e gerenciamento de produtos de forma prática e organizada. A plataforma permite que o cliente se registre no sistema, cadastre produtos para venda, defina preços e os adicione ao carrinho.

Além disso, o sistema oferece funcionalidades de gerenciamento, possibilitando editar e remover tanto clientes quanto produtos cadastrados, garantindo maior controle e flexibilidade na administração da aplicação.

O objetivo do projeto é proporcionar uma experiência simples e eficiente de compra e venda em ambiente virtual, simulando as principais funcionalidades de um comércio eletrônico moderno.

No arquivo enviado, tem um "setup.bat" que ao clicar, ele ja vai fazer todo o processo da execução e abrir o programa com o site
